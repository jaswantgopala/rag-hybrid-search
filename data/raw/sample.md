# Employee Onboarding Guide

## Setting Up Your Development Environment

Before you start, install Python 3.11 or higher and clone the internal repository using `git clone`. Make sure you have access to the VPN, as several internal services are only reachable from the company network.

## Requesting Access to Internal Tools

To request access to Jira, Confluence, or the internal API gateway, submit a ticket through the IT Service Desk portal. Approval typically takes 1-2 business days. For urgent access needs, contact your manager to escalate the request.

## Code Review Process

All pull requests require at least two approvals before merging to `main`. Reviewers should check for test coverage, adherence to the style guide, and documentation updates. The CI pipeline must pass before a PR can be merged.
