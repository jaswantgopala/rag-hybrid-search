# Customer Support Escalation Process

## Tier Structure

Support tickets start at Tier 1 (general inquiries), and escalate to Tier 2 (technical issues) if unresolved within 4 hours, then to Tier 3 (engineering) for bugs requiring code changes.

## Escalation Triggers

A ticket should be escalated immediately, regardless of tier, if it involves a data loss report, a security concern, or a customer threatening to churn an enterprise contract.

## Response Time SLAs

Enterprise customers have a 1-hour first-response SLA. Standard customers have a 24-hour first-response SLA. SLA breaches are automatically flagged in the support dashboard and reported weekly.

## Engineering Handoff

When a ticket escalates to Tier 3, the support agent must attach reproduction steps, affected account IDs, and relevant log snippets before handing off, so engineering doesn't have to re-gather context.
